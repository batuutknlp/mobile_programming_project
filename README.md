## Problem

When exploring an unfamiliar area with friends, finding a restaurant that suits everyone can take too long. General map searches offer useful listings and reviews, but it can be difficult to narrow and compare options against practical group needs—such as cuisine, budget, student discounts, Wi-Fi, power outlets, and opening status. Broad results and dense screens can make it harder to reach a quick, confident choice.

## Solution

We’re designing an iOS restaurant-discovery experience that makes nearby options easier to filter and compare. Users can search by location, category, cuisine, price, amenities, rating, and open status, then sort results and scan clear map markers. Each restaurant page brings its rating, key features, photos, and map action into one easy-to-scan view.

## Prototype data

This university project focuses on the search experience and interface design. Depending on the implementation, the prototype may use sample data or data from a provider such as Google Places. The README and app should clearly distinguish demo data from live data and avoid implying that information is live when it is not.
